# Password Manager PHP Projektas

Slaptazodziu generatorius ir saugykla sukurtas naudojant PHP OOP.

Naudotos technologijos:
- PHP
- MySQL
- HTML
- CSS
- PDO
- AES sifravimas
- password_hash

Funkcijos:
- vartotojo registracija
- prisijungimas
- atsijungimas
- slaptazodziu generavimas
- slaptazodziu saugojimas
- AES sifravimas
- validacija

Paleidimas:
1. Importuoti database.sql i phpMyAdmin
2. Paleisti XAMPP Apache ir MySQL
3. Atidaryti:
http://localhost/password-manager
